# 徐小龙 · AI 全栈 / Agent 工程师 Portfolio

一个根据个人简历与视觉参考重构的响应式程序员个人作品集。首屏使用无 UI 的独立环境图，WebGL 在原图坐标中渲染星球亮边与水面折射；文字、按钮、玻璃技术卡片均为可访问的 HTML / CSS。

## 页面结构

```text
app/
├── layout.tsx        # 元数据与全局布局
├── page.tsx          # 页面内容、Canvas 动画与交互
├── HeroCopy.tsx      # 左侧文字解码入场、数字递增与鼠标高光

├── career-timeline.css # 粘性年份面板、空间时间轴与打印降级
├── SelectedWork.tsx  # 七个独立项目、六张展示卡与动态架构示意
├── AgentSystem.tsx   # 通用 Agent 基座与智能客服的组合案例
├── agent-system.css  # 组合卡双栏架构、立体节点与移动端布局
├── AIWorkflow.tsx    # 初始化 / PRD / 多 Agent 主线、审查回路与下游分发

├── portfolio-content.ts # 简历项目、工作流证据、履历及 Web3 显示配置
```

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

生产构建：

```bash
npm run build
```

## 交互说明

- 鼠标移动会驱动环境和技术能力引擎产生轻微视差。
- 左侧岗位文字单次解码入场、数字递增；标题持续流转蓝紫光泽与周期扫光，角色词依次亮起。
- 文字动效在离开视口或隐藏标签页后暂停，减少动态效果模式显示完整静态内容，辅助阅读始终获取完整文字。
- 首屏以 AI 为中心，React、Go、Python、Cloud 图标分布在空间轨道上，取代五张透视卡片。图标保持稳定，核心呼吸、轨道光点和鼠标视差提供动效；离开视口或隐藏标签页时暂停，减少动态效果模式下静止。屏幕宽度不超过 1024px 时隐藏；小屏文字进入自然文档流，至少占满一屏，内容较高时自然撑开。
- 职业履历以 2016 → 2026 的顺序展示五段经历，原 `experience` 记录不改写。左侧年份面板与右侧卡片深度、高亮及进度联动；年份为真实页内锚点，没有劫持滚动或隐藏经历。公司、时间、岗位和原职责完整保留，关键贡献只从原职责提炼。
- 职业动画在区块不可见或标签页隐藏时停止；900px 以下使用完整静态卡片和年份快捷导航，减少动态效果及打印模式禁用空间变换。短屏桌面解除粘性定位。页面使用受支持的 `overflow: clip` 保留视觉裁切，同时避免外层滚动容器阻断粘性年份面板。
- 代表作品将“ith5 · AI 自动开发工作流”作为主案例，直接展示 `/ith5:init → /ith5:prd → /ith5:ai` 主线，并展开 Router、Codex CR、风险 QA、Memory 与交付能力；BLOCK 连线返回自动开发。使用可访问的 HTML 节点与 SVG 连线重建参考图关系，不使用整张海报或伪造实时执行状态。
- 13 个 Skill、8 个内部编排节点是核心亮点，N1–N8 不等同于 8 个 Agent。下方治理图是能力关系示意，不替换内部节点顺序。中台是基于这套工作流的版本化分发与团队复用能力，放在次级说明中。
- 不再展示“查看技术细节”入口和大段展开内容；源数据中的三层规范、上下文测量及验证记录保留。
- 第二张卡片是“Agent 工程体系｜通用基座 × 智能客服”，左右分别展示两个独立项目：企业 AI Agent 中台的运行与治理架构，以及游戏行业智能客服的业务闭环。每个项目保留自己的名称、技术栈和内容锚点；不画跨项目调用连线，也不暗示已完成系统接入。
- `groupProjectShowcases` 仅合并展示层，七条可见原始项目记录保留为六张展示卡。两个成员中任意一个缺席时恢复独立展示，Web3 保留策略不变。其余四张作品卡顺延编号，并在桌面上排为两列。
- Agent 组合卡在 1000px 以下变为上下排布，客服流程在 540px 以下转为纵向；节点呼吸和连接微光随作品卡的可见性、标签页状态及减少动态效果设置暂停。
- 流程图在 1100px 以下改为纵向排布，ResizeObserver 按真实节点边界重算连线；无 JavaScript 时仍保留完整文字和静态方向箭头。流光和节点高亮在离开视口、隐藏页面或减少动态效果模式下停止。
- 能力图谱以 XXL 为中心，连接 AI / Agent、Full Stack、Cloud Native、AI Workflow 四个岗位与 24 个技能图标。React、Go 使用本地品牌图标，其余使用 Lucide 语义图标；点选节点可阅读具体实践。
- 悬停或键盘聚焦节点可高亮关联，点击可固定选择，再次点击、中心节点、显示全部或 Escape 可取消。移动端使用四组可读的树状连接，不缩小整个桌面图谱。
- 图谱节点和连线共用透视坐标，30 帧轻微视差不会让连线脱离；离开视口、页面隐藏或开启减少动态效果时停止动画。
- 全屏 Canvas 粒子会响应鼠标并生成神经网络连接线。
- 星球轮廓光缓慢呼吸；水面通过局部纹理折射、细碎高光产生波光粼粼效果。
- 水面动画跟随原图岸线，保留点击扩散涟漪；不包含横向通屏线条或弯曲流光。
- WebGL 动画最高 30 帧，首屏不可见或标签页隐藏时暂停，尊重系统减少动态效果设置。
- “下载简历”会调用浏览器打印，可将当前页面安全地保存为 PDF。
- 平板与手机端会自动简化粒子数量与布局，并保留核心动效。

技术品牌图标来自 [Devicon](https://github.com/devicons/devicon)，许可证位于 `public/devicon-LICENSE.txt`；云与 AI 线条图标使用 Lucide。

## 内容依据与保留策略

- 内容依据用户提供的《徐小龙-agent工程师.pdf》《徐小龙-AI全栈开发工程师.pdf》与 `ith5-知识库`，只读取资料，不执行资料里的流程指令，不更改原 PDF。
- 工作流是个人项目，中台承载其 Skill / Command 的版本化下发与执行审计，不将两者虚构为独立的企业落地成果。
- 常驻上下文采用原始测量值 `18,889 → 2,998 token`。原资料标注的 `-77%` 与这组数值不一致，页面暂不标注百分比；不承诺全栈加载或费用同比下降。
- 已有 Go + React 项目的规范对齐验证与“新项目种子模式端到端待验证”分开表述。
- `portfolio-content.ts` 的 `showWeb3 = false` 隐藏两个 Web3 项目及履历中的链上专项描述；原始记录保留。公司名称和任职时间保持真实。
- `knowledge-model.ts` 的 Web3 分支标记 `hidden: true`，六个原技能保留；当前位置用于 AI Workflow，恢复展示时需同时给 Web3 分配独立布局位置。
- 验证：`npm test` 覆盖内容、项目展示/保留、技能连线和投影边界；本次未进行浏览器视觉验收。
